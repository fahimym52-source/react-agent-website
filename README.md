# React Agency Website

A modern, responsive agency website built with React and Tailwind CSS, featuring a portfolio showcase, contact page, authentication flow, and a protected dashboard.

## About the Project

This project is a responsive agency website designed to showcase services, portfolio projects, team members, and company information through a clean and user-friendly interface.

It also includes a login system and a protected dashboard. Users must log in before accessing protected pages, demonstrating authentication flow and route protection in React.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern user interface with Tailwind CSS
- Home page with hero section
- Services section and dedicated services page
- Portfolio showcase
- About section
- Team members section
- Contact page with form validation
- Login page with input validation
- Protected routes for authenticated users
- Dashboard with sidebar navigation and data visualization
- Profile page
- Reusable React components
- Client-side navigation with React Router

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the URL of your GitHub repository.

### 2. Navigate to the project directory

```bash
cd react-agency-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
