# React Agency Website

A modern and responsive agency website built with React and Tailwind CSS.

## About the Project

This project is a responsive agency website designed to present services, showcase portfolio projects, introduce team members, and provide contact information through a clean and user-friendly interface.

## Features

- Responsive website layout
- Modern user interface
- Services section
- Portfolio showcase
- Team members section
- About section
- Contact section
- Reusable React components

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite
- React Icons
- React Router

## Getting Started

To run this project locally, follow these steps.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the URL of this GitHub repository.

### 2. Navigate to the project directory

```bash
cd react-agency-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.
